# WindowTab logo

Generated with the built-in imagegen tool, transparent background. The original generated PNG is preserved; the Windows ICO contains resized packaging derivatives only.

## Prompt

Use case: logo-brand. Asset type: production Windows desktop application icon and settings logo for WindowTab, a utility that smoothly switches between application windows. Create one refined liquid-glass logo mark only: two compact overlapping rounded window panes, offset diagonally, front pane shaped as a clear rounded rectangle with a subtle small tab notch on its top edge, suggesting a window/tab moving forward. Thick polished translucent optical glass with frosted pale-blue body, crisp silver-white rim highlights, restrained cobalt blue refraction along lower/right edges. The silhouette must be simple, bold and instantly readable at 24px; no tiny interface elements. Nearly front-facing, minimal depth and gentle bevels, premium native desktop app feeling. Single centered mark fills approximately 82% of square image, generous clean margins. Real transparent background with alpha, not a checkerboard drawn in the image. No enclosing app tile, no letters, no words, no arrows, no watermark, no extra objects, no large cast shadow. Keep all visible glass material luminous enough for both light and dark backgrounds.
