# WindowTab v0.1.3 — Transparent taskbar

WindowTab can now hide the Windows taskbar background and its top border while keeping the taskbar controls visible.

## Added

- **Taskbar trong suốt** (Transparent taskbar) on Windows 11 22H2 or later (x64). The option is off by default.
- To enable it, open **Cài đặt → Ứng dụng → Taskbar trong suốt** and select **Lưu thay đổi**. The system tray menu also has a **Taskbar trong suốt** toggle for quick access.
- Turn the option off or exit WindowTab to restore the Windows taskbar appearance.

## Verification

All 18,075 motion checks passed. The Settings toggle was checked for loading the saved value and saving in both directions. On Windows 11 25H2, WindowTab detected a stale Explorer module and reconnected after Explorer restarted, loading the new module and reporting that the effect was applied.

## Upgrade

Exit WindowTab using **Thoát** in the system tray. Extract the entire **WindowTab-win-x64.zip** archive into your permanent app folder and launch **WindowTab.exe**. Keep **WindowTab.Taskbar.dll** beside the executable. Your preferences are stored in `%LOCALAPPDATA%\WindowTab\settings.json`.

Exit TranslucentTB before enabling the feature. If WindowTab reports that Explorer still holds the TranslucentTB module or an older WindowTab module, restart Windows Explorer or sign out and back in.

The x64 package includes the .NET runtime. The build is unsigned, and **SHA256SUMS.txt** contains the ZIP checksum. See the [English quick start](https://github.com/nguyenquocan0101/WindowTab/blob/main/docs/quick-start.en.md) for setup.
