# WindowTab v0.1.2 — Let the window move, not the background

Switching from a full-size app to a floating window now feels like bringing that window into view, rather than sliding the entire screen away.

## Fixed

- A floating window entering over a full-size app animates above a stationary background.
- Switching back moves the floating window out while the full-size background stays fixed.
- Floating previews stay above the background in both directions, including rollback when focus activation fails.
- Existing transitions between two full-size windows, the fixed taskbar, and Desktop boundary settings are preserved.

## Verification

Motion regression checks cover transition selection, stationary backgrounds, geometry, and both swipe directions. Real DWM previews were also checked in both layer orders, with runtime checks for cancellation and activation rollback.

## Upgrade

Exit WindowTab using **Thoát** in the system tray, extract **WindowTab-win-x64.zip** into your permanent app folder, and launch **WindowTab.exe**. Your shortcuts and timing preferences remain in `%LOCALAPPDATA%\WindowTab\settings.json`.

The Windows x64 package includes its .NET runtime. The app is unsigned; **SHA256SUMS.txt** contains the package checksum. See the [English quick start](https://github.com/nguyenquocan0101/WindowTab/blob/main/docs/quick-start.en.md) for setup.
