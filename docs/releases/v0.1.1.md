# WindowTab v0.1.1 — A fresh look, everywhere

WindowTab's liquid-glass identity belongs on your desktop, too: the app icon, Settings title bar, taskbar, and system tray all use the same WindowTab logo in this release.

## In this release

- Ship the current branded Settings interface and app icon as version **0.1.1**.
- Read the release package version from the project by default, so local packages and GitHub builds stay in sync. An explicit `-Version` override is still supported.
- Keep the existing shrink, slide, and zoom transitions, fixed taskbar, and configurable Desktop boundary behavior.

## Upgrade from an earlier build

1. Exit WindowTab from its system tray menu (**Thoát**). Only one copy can run at a time; opening a newer executable while an old copy is running leaves the old copy active.
2. Download **WindowTab-win-x64.zip**, extract the entire archive into a permanent folder, and start **WindowTab.exe**.
3. If **Start with Windows** is enabled, launching the new copy updates the startup entry to its new location automatically.
4. Once the new copy is running, remove the old extracted app folders and shortcuts that point to them.

Your settings stay in `%LOCALAPPDATA%\WindowTab\settings.json`; keep this file to preserve your shortcuts, timing, and Desktop preference. The UI currently uses Vietnamese. See the [English quick start](https://github.com/nguyenquocan0101/WindowTab/blob/main/docs/quick-start.en.md) for setup and label translations.
